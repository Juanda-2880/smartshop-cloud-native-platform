# SmartShop Cloud Native Platform

Objetivo:

Construir una plataforma e-commerce cloud native
desplegada sobre Kubernetes usando Minikube.

El proyecto demostrará:

- Kubernetes
- Observabilidad
- HPA
- SSO
- Cost Management
- Blue Green Deployment
- Canary Deployment
- ELK
- OpenTelemetry
- Prometheus
- Grafana
- Kubecost

No se utilizará Terraform.

El entorno objetivo es Minikube v1.39.0.
